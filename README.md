# 🔢 Sum of Numbers from 1 to 100

A beginner Python program that calculates the sum of all integers from 1 to 100 using a `for` loop and the `range()` function.

This project is part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

## 📌 About the Project

The program calculates the total of every integer from 1 to 100.

It begins by initialising a variable called `sum` to `0`. A `for` loop then iterates through the numbers generated by `range(1, 101)`, adding each number to the running total.

Once the loop finishes, the program prints the final sum.

## 🛠️ Technologies & Concepts Used

- **Python 3** – the programming language used.
- `for` loops – to iterate through a sequence of numbers.
- `range()` – to generate integers from 1 to 100.
- Variables – to store the running total.
- `+=` operator – to update the total by adding each number.
- `print()` – to display the final result.

## 📚 What I Learnt

Through this exercise, I practised several fundamental Python concepts:

1. **For Loops** – repeating instructions for every number in a sequence.
2. **The `range()` Function** – generating a sequence of integers. I learnt that the ending value is excluded, which is why `range(1, 101)` generates numbers from 1 to 100.
3. **Accumulator Variables** – using a variable to keep track of a running total as a loop executes.
4. **Augmented Assignment (`+=`)** – adding a value to an existing variable and updating it in one operation.
5. **Iteration** – understanding how Python processes elements one at a time.
6. **Basic Arithmetic** – using addition repeatedly to calculate a cumulative sum.
